# Third-party licences for the API reference viewer

The API reference pages embed [Redoc](https://github.com/Redocly/redoc), which
`build.sh` downloads at a pinned version rather than committing here, dressed in
the [redark](https://github.com/dilanx/redark) dark theme, whose `redark.css`
and `redark.js` are vendored alongside this file because they are small enough
that a download would cost more than it saved.

Both are MIT licensed.
